# ذَكِّرني — Zakkerni

رفيقك في الذكر اليومي: أذكار الصباح والمساء والنوم (حصن المسلم)، مواقيت الصلاة والأذان.

- `android/` مشروع تطبيق الأندرويد (WebView + أذان في الخلفية عبر AlarmManager).
- `web/` نسخة الويب القابلة للتثبيت (للآيفون عبر Safari ← إضافة إلى الشاشة الرئيسية).
- `.github/workflows/build.yml` يبني APK و AAB تلقائيًا وينشر نسخة الويب على GitHub Pages.
